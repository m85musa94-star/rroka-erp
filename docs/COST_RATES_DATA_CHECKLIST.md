# قائمة بيانات معدلات التكلفة — للمراجعة عند الإدخال

> حُفظت بطلب صاحب المشروع (2026-10-08) لمراجعتها معًا عند بدء إدخال الأرقام الحقيقية.
> **لم يُتفق على أي رقم حتى الآن** — القاعدة الحاكمة ٢ (Zero Assumption): لا يُدخل معدل تقديري أو متوسط صناعي؛
> كل معدل يُحسب من بيانات فعلية يقدّمها صاحب المشروع، ثم يُدخل في «محرك التكلفة» ويُعتمد.

| المعدل | البيانات الفعلية المطلوبة | المصدر |
|---|---|---|
| **أجر ساعة العامل** (لكل موظف إنتاج) | الراتب الأساسي، والبدلات، والتأمينات (GOSI)، والإقامة ورسومها، والتأشيرة، والتأمين الطبي، والسكن والنقل إن وُجدا، وأيام وساعات العمل الفعلية شهريًا، والإجازات | العقود وكشف الرواتب وفواتير الرسوم |
| **تكلفة ساعة الآلة** (لكل ماكينة) | سعر الشراء (المكائن المستعملة)، والعمر الإنتاجي المتوقع الذي يقرره صاحب المشروع، واستهلاك الكهرباء بالكيلوواط، والصيانة وقطع الغيار السنوية، وساعات التشغيل الشهرية | فواتير المكائن وفواتير الكهرباء والصيانة |
| **سعر الكيلوواط** | قيمة فاتورة الكهرباء ÷ الاستهلاك | فاتورة الكهرباء |
| **التكاليف الصناعية غير المباشرة** | إيجار الورشة، والكهرباء العامة، وأجور غير مباشرة (مشرف، عامل نظافة)، ومستهلكات الورشة — شهريًا | عقد الإيجار والفواتير |
| **المصروفات الإدارية والبيعية** | رواتب الإدارة، والرسوم الحكومية، والاتصالات، والتسويق — شهريًا | الفواتير والكشوف |
| **الأسعار المعيارية للخامات** | سعر آخر شراء لكل خامة | فواتير الموردين |
| **نسب الهالك** | نسبة الهالك الفعلية لكل خامة أو فئة (مثل ألواح MDF) | تجربة الورشة |

## خطوات العمل عند استلام البيانات
1. مراجعة البيانات (اكتمال، تواريخ، تعارضات) وبيان الناقص وأثره.
2. حساب أجر ساعة كل عامل، وتكلفة ساعة كل آلة، ومعدل تحميل غير المباشر — مع المعادلة لكل رقم.
3. مراجعة النتائج مع صاحب المشروع.
4. الإدخال في «محرك التكلفة» (بطاقات الموظفين والآلات، أوعية التكاليف، الأسعار المعيارية، الهالك) ثم الاعتماد.

## قرارات مطلوبة من صاحب المشروع قبل الحساب
- العمر الإنتاجي لكل آلة (وسياسة الإهلاك — مطلوبة أيضًا للمحاسبة).
- ساعات العمل الشهرية المعتمدة وما يُستبعد منها كوقت غير منتج.
